## Overview

GymShock is an AI-driven mobile fitness platform designed to democratize access to structured boxing training, combining computer vision, personalized progression, and community-based accountability to reduce injuries, improve retention, and generate measurable health impact.

**Current Status:** an offline-first mobile platform for boxing technique analysis and progress tracking using computer vision and wearable data.

## Key Features

- **AI-Driven Training Progression**: Personalized technical progression powered by computer-vision-assisted analysis and adaptive training logic to reduce injury risk and support long-term retention.
- **High-Performance Mobile Vision Pipeline**: High-FPS camera pipelines built with React Native and Android Studio to support real-time computer vision features.
- **Secure User Infrastructure**: Secure authentication and persistent session management using Zustand, designed for scalable user growth.
- **Inclusive Design System**: Centralized Tailwind CSS tokens for consistency across the app, ensuring accessibility and responsive design that works for users on any device and level of technical competence.
- **Impact Measurement Framework**: Built-in metrics to track technical progress, retention, and health indicators to support evidence-based evaluation.*

## Technologies and tools used to bring this project to life

- **Mobile**: React Native (Expo), Drizzle ORM, SQLite, TypeScript.
- **Backend**: FastAPI, SQLAlchemy, PostgreSQL, OpenCV, MediaPipe
- **Design**: Centralized token system enabling scalable theming and consistent user experience following the Figma design
- **Real-Time & Streaming Data (Planned / In Progress)**: Kafka, Spark Streaming, Databricks, Azure Data Lake

## Challenges and Learnings

The primary challenge was not technical, but human. Research revealed that over 70% of individuals abandon exercise routines due to psychological barriers rather than lack of access. This required designing the platform around safe progression, confidence-building, and community trust, rather than traditional performance-driven fitness models.

On the technical side, delivering high-FPS mobile computer vision while maintaining performance, battery efficiency, and session stability required careful pipeline optimization and close collaboration with data and backend teams.
## Outcome

GymShock demonstrates how AI-driven mobile technology can bridge the gap between informal sports practice and structured, scalable health interventions. The platform lays the groundwork for measurable impact in injury prevention and retention.
**Project Impact**: Reduces injury risk via structured, validated technical progression

**Technical Achievements**: AI-integrated mobile architecture supporting computer vision features

Modular architecture designed for pilot validation and future public-private partnerships
