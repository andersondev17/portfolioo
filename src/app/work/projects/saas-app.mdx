## Overview

**Saas Learning Companion App** is an AI-powered Learning Management System (LMS) designed to adapt to the learner, not just the syllabus. It combines interactive learning sessions with a personal AI companion that tailors content and engagement to each user.

The app features secure authentication, subscription management, and error monitoring, creating a scalable, maintainable, and responsive platform.

## Key Features

- **AI Vocal Agent:** Delivers interactive learning sessions and responds to user inputs.  
- **Personalized Learning:** Learns the user’s style to adapt content dynamically.  
- **User Authentication & Subscriptions:** Managed securely via **Clerk**.  
- **Error Monitoring:** Real-time tracking and alerts using **Sentry**.  
- **Interactive UX:** Smooth, accessible, and responsive interface built with Tailwind CSS.  

## Technologies Used

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, ShadCN/UI  
- **Backend / Services:** Supabase for database and auth integration  
- **Authentication:** Clerk  
- **AI Integration:** VAPI-AI for vocal AI interactions  
- **Monitoring:** Sentry for error tracking  

## Project Impact

- Enabled personalized, interactive learning for users.  
- Simplified subscription and authentication flows.  
- Delivered a scalable architecture for real-time AI-powered interactions.  
- Provided a responsive and accessible UI for all devices.
