## Overview

A full-stack accommodation eCommerce platform inspired by Nike, enabling users to explore products and process secure payments. Built on Next.js 15, the platform adopts a Server Actions–based monolithic architecture, reducing the need for traditional REST APIs.
## Key Features

- **Server Actions Architecture**: Business logic implemented using Next.js Server Actions, resulting in fewer layers, cleaner code, and easier long-term maintenance.
- **WhatsApp Integration**: Orders go straight to merchant's WhatsApp - no complex setup needed
- **Frontend**: Designed and implemented a responsive React frontend with Tailwind CSS and Integrated Mercadopago for secure payment processing
- **Performance**: Optimized app performance using lazy loading and pagination

## Technologies Used

- **Frontend**: Next.js 15, React, TypeScript, Tailwind CSS
- **Backend**: Next.js Server Actions
- **Auth**: Better Auth
- **Database**: Neon PostgreSQL, Drizzle ORM
- **Security**: Protection with rate limiting.

## Project Impact

- Improved UX with smooth shopping flow and fast load times
- Achieved responsive performance across devices
